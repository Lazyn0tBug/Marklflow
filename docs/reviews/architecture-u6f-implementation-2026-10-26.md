# U6f 三视图与布局设置实施审查

日期：2026-10-26；分支：architecture-refactor；父提交：3b84346。范围为草案6 U6f；审查验证后一次本地提交，不推送。

## 基线差异与修复

开始时工作区干净，U6e已提交。现有显隐/设置控件和基础同步可以工作，但旧App仅按标题与固定24像素行高插值，长章节内的代码、段落及无标题内容只能近似整体比例；生成完成后、flow/A4切换及隐藏视图重挂载也缺少统一语义位置衔接。既有大纲scrollIntoView会滚动祖先工作台，与窄屏内部横滚规则冲突。

新增展示层sourceScroll工具，读取现有产物data-line/data-source-end，不改变Worker协议、缓存结构或渲染引擎。按内层语义块建立单调源码行/像素坐标，包含标题、段落、列表、代码、公式、图表和表格行；合并A4同一代码块的分页片段区间，重复表头不推进源码。缺少源码块时退化到文档边界，区间内使用线性插值；不是字符级或每个分页切点的精确测量，不承诺将图片、公式或分页留白映射成源码字符。标题点击落到对应源码行与标题起点，常规滚动按块区间对应，而非整篇滚动比例。

编辑器wrap=off的既有行为保持，行坐标改为读取实际line-height/padding；隐藏时保留最近一次测量值。编辑器滚动按视窗中心源码行高亮章节，同时以顶部源码位置同步预览；HTML滚动按源码坐标同步编辑器，并高亮HTML中心对应章节。顶端/末尾吸附保留。同步暂停时两侧可独立滚动，大纲选中仍明确定位两侧。程序滚动使用预期目标抑制反向事件；真实输入清除对应标记，不再保留600/90毫秒方向锁和smooth滚动计时器。

## 新产物与会话衔接

预览未就绪时不读取旧DOM驱动编辑器。生成中点击大纲只保留当前文档的一个目标行，新完整产物挂载后应用；切换Tab清除旧待定位目标。新产物就绪后按当前编辑器位置衔接，缓存切回优先恢复会话保存位置。flow/A4切换保留源码位置，不把两种排版的像素值直接互用。

HTML隐藏期间编辑器继续滚动，再显示HTML时按当前源码位置定位；编辑器隐藏期间滚动HTML，会更新该会话待恢复的编辑位置。ResizeObserver仅观察实际视窗尺寸变化，重新读取现有DOM坐标，不启动生成任务；组件卸载和产物替换时断开观察。内容最大宽度和显隐改变只调整展示，保留相同缓存引用。

大纲高亮现在只调整大纲列表scrollTop，不调用滚动祖先的scrollIntoView；列表切回大纲页签时也能呈现当前高亮。保留原有高亮边框/字重及语义aria-current，不改界面风格。

三视图仍由用户独立控制：7种非空组合，最后一个不可隐藏，开启的视图同时显示，空间不足仅工作台横向滚动。配置默认隐藏，在原生dialog中打开；默认1024px，800px及full选项同时作用于编辑器与流式HTML。A4继续保留物理页宽，宽度设置不改变导出纸张。

## 审查与验证

新增5项单元：块内双向插值/边界、平坦和空映射、测量行高与内边距、A4代码片段与重复表头、内层块优先/无效区间/单调坐标。

新增4项真实生产工作台Chromium用例：长段落/长代码双向定位与中心高亮及暂停同步；A4标题居顶、反向定位、Tab缓存引用/位置恢复；隐藏后恢复、1024/800/full配置、A4七种非空组合与窄屏横滚不受大纲高亮干扰；生成中点击大纲后定位及无标题文档同步。沿用原三视图和U6e六项Tab回归，不向产品增加测试API。测试编写中修正了同步控件定位、Tab标题假设和浏览器evaluate参数传递错误，不为测试改变产品交互。
