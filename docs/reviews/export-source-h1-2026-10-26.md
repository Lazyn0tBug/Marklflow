# EX-H1 统一HTML产物契约实施与审查

基线：EX-H0 / 55fcf1c。生产范围仅HTML准备与语义保留，不迁移全部格式端口，不实现OMML或Tauri PDF。

## 实现

- 新增纯模型exportHtmlSchema/ExportHtmlArtifact：版本、来源ID/修订/MD SHA-256与渲染配置指纹、元数据、净化HTML、文档CSS/变量/A4边距、冻结资产及诊断。无Markdown/文档对象/编辑附件/DOM节点；各层只读并在运行时冻结，可序列化往返。
- prepareExportContent在首次await前复制并校验来源/选项，一次渲染、一次资产收集；重复URL只读取一次，资源数据/字节数/MIME/SHA-256保留。配置指纹含约定版本、主题、语法/公式模式、CSS和实际资产散列；不包含瞬态SVG ID，产物UTF-8正文/CSS受50MiB限制。
- SVG公式在同一次MathJax TeX编译返回根上调用已有startup.toMML序列化，不重新解释LaTeX。短暂编译捕获仅在所属隔离会话和共享DOM步骤内安装，finally恢复方法及基线；错误/未知命令拒绝发布。隐藏MathML与展示SVG同属于带原始偏移ID/行范围的公式HTML节点。
- 保留现有document/html兼容字段到EX-H2；新artifact与这些可变兼容字段无共享可变对象。DOCX图片输出跳过隐藏语义副本，避免把同式额外输出普通文本；原生OMML未实现。

## 审查修复

| 问题 | 修复与覆盖 |
| --- | --- |
| 带编号公式的嵌套SVG合法引用外层defs，被最近SVG校验误拒 | 整幅外层SVG一次命名空间化并按整幅图校验；不同图仍不能相互借字形；真实编号公式与嵌套单元回归 |

| SVG附带MathML可能双重输出 | 隐藏MathML可序列化且浏览器不可见；DOCX旧图像路径跳过语义副本 |

## 验证与边界

验证通过：173个受管源文件/配置均在严格类型检查覆盖范围；源文件策略、模块边界、lint、327项单元测试和生产构建通过。完整Chromium回归83项通过（4.7分钟），其中新增3项覆盖开发、构建及普通HTTP的真实MathJax/HTML契约。见[证据清单](../acceptance/export-source-h1-evidence.json)。首轮缺少mock导出及真实嵌套SVG校验失败已修复，最终结果为上述全量通过；旧失败日志不作成功证据。新增真实MathJax夹具覆盖开发/生产构建/普通HTTP、两种模式、行内与块级、跨文档宏/编号、同文档重渲染、脚注重排、未知命令恢复、文档样式装载与语义副本隐藏状态、重复资产只读一次及来源修改隔离。固定EX-H0语料不改写；浏览器夹具将单行双美元样例扩为块级以补充块公式验证。

没有引入依赖、Chromium或Puppeteer；Playwright沿用已有开发测试环境，不进入应用发行包。MathJax 3.2.2/Paged.js 0.4.3不变。不宣称格式端口全部只接HTML（EX-H2未实施）、原生公式、系统PDF默认名修复、用户系统保存验证、Word/WPS或Tauri通过。

审查收口：保留旧document/html兼容字段与格式级Markdown预检到EX-H2；本步不冒称整个HTML唯一输出源迁移完成。PNG资源、样式/边距和数学语义是契约内容；系统字体仅保留本地回退声明，不宣称所有字体均已嵌入。H0语料SHA-256复核未变；package.json未修改，无新增锁文件。已有构建大chunk及hash.js混合静态/动态导入提示保留为既有提示。
