# U6a 共享DOM串行入口实施审查

日期：2026-10-25；分支：architecture-refactor；父提交：05b51dc。范围为草案6 U6a；一次本地提交，不推送。

## 实现和边界

SharedDom是纯应用层的一个串行入口，只调度调用方提供的步骤，不直接访问document，也不创建Worker、DOM宿主池或通用工作流。组合方为所有DOM使用者提供同一实例。每步结束且局部清理完成后，重新按导出、前台、后台优先级选择下一项，同优先级FIFO。一个渲染任务可以逐步await共享入口，步骤间允许高优先级任务先执行。正在执行的同步调用、异步引擎调用和清理均不抢占。

每步有局部CleanupList。排队取消直接移除，未执行步骤不启动执行计时；活跃步骤取消或超时仅发出AbortSignal并拒绝最终产物，必须等调用返回及清理结束才释放DOM入口。清理失败阻塞共享入口，保留失败列表，只有显式重试清理成功才能继续。不存在自动重试渲染。资源读取15秒、普通引擎20秒、分页60秒均引用A0冻结值；不增加排队期限。同步阻塞期间浏览器不能执行计时器，返回后再检查超期；不宣称硬中断或硬实时期限。清理必须实际结束，超时不能作为已释放证明。

RoleTaskScheduler增加可选prepareDom端口，原来的同步generated提交端口保持不变。计算结果返回后，物理Worker已空闲，但逻辑角色槽位继续保持running并计入候选产物估算；同角色下一任务不能派发。DOM结束后重新校验产物结构、taskId门禁和输出预算，再进入原同步完成提交；取消或作废结果不提交。等待/执行DOM期间延续从原计算派发开始的总期限，不重置总计时，不建立排队超时；总期限届满作废结果，但保留槽位直到准备阶段退出。替换角色Worker也必须等DOM阶段释放。后台产物发布规则、唯一缓存和原协调器保持不变。

prepareDom负责把实际引擎步骤送入共享实例；这个端口当前仅在夹具使用。现有PreviewActivation、MarkdownWorkerRuntime生产组合以及导出生成函数尚未接入该端口。export只是共享入口优先级，不重新进入预览任务队列，原ExportService的busy与冻结快照边界不改。真实MathJax、Mermaid、Paged.js接入分别留给U6b/U6c/U6d，应用UI和生产双角色仍未启用。

## 审查与验证

审查补齐了DOM等待期间保留逻辑角色、保留原总期限、准备产物重新过严格结构校验、迟到结果不能提交、同步超期返回后检查，以及DOM释放前不能替换角色实例。未引入通用池、租约、预算表或额外宿主。

新增11项单元覆盖优先级/FIFO、步骤边界让位、排队取消、活跃超期及异步清理保留入口、清理失败阻塞和显式恢复、资源/分页期限、引擎异常清理、DOM取消保留角色、原总期限及迟到结果、产物校验与成功提交，以及准备回调不能改写调度器持有的任务身份。真实浏览器夹具使用单个MarkdownWorkerAdapter解析，通过受控后台步骤占用DOM，验证前台等待仍占原槽位、导出在边界先行、同角色下一需求等待、旧任务不提交以及真实article宿主清理。开发构建、生产构建和普通HTTP三种环境均验收；夹具没有调用真实公式/分页引擎，也不是生产双角色启用。

完整验证：bun run check通过，四份严格类型配置覆盖134个受管源/配置，源策略、模块边界和lint通过，38文件250项单元通过，生产构建通过。完整Chromium回归结果见[验证证据](architecture-u6a-evidence-2026-10-25.json)。Vite原有配置加载与大分块提示、NO_COLOR/FORCE_COLOR提示保留。没有进行其他浏览器、Tauri或实体打印验收。

MathJax 3.2.2、Paged.js 0.4.3、锁文件及A0冻结预算/基线证据保持不变。未修改UI、存储、原渲染/导出路径和解析算法；未合并、未移动标签、未推送。U6b及后续按草案6另行实施。
