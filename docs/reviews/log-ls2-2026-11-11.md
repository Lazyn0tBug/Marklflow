## 实现边界

- page_ready 使用 run 根上下文；无 ID 的全局 page_error 也使用 run。根上下文单独生成，parent_id 固定为 null，不能调用把父级填为根 ID 的子 span 辅助函数。
- 有有效关联 ID 的调用事件和调用级 page_error 保持 page_call；ID 校验、来源身份注入、通道回执与清理规则不变。缺 ID 的调用事件也不制造 page_call，挂 run 但继续由校验器明确标为未关联。
- 校验器检查根父级为空，并在 run_start 提供根 ID 时核对身份一致；不能用另一条页面根记录替代原生 run_start 确认根 ID。
- 同名无关联页面错误可以多次出现于同一 run，不再仅凭共享 span+事件名判定重复。关联 page_call 的开始/完成与重复检查继续按原规则执行。
- 没有新增 IPC 参数、日志字段、授权能力或新的常驻状态；LS1 保持，14 天保留/取消数量与总量限制的 LS3 仍未实施。
