# LS1：非法调用关联 ID 不影响业务

日期：2026-11-11。分支：architecture-refactor。基线：55285f2。范围仅限日志设计 §6.2 LS1；不实施 LS2/LS3 或 Rust 模块整理。

## 变更

受保护命令仍从 Tauri 注入的 WebView 取得原生身份，经过相同来源守卫再执行业务。合法 call_id 进入 command span；缺失/非法值按无关联处理，不再返回诊断性的 invalid-payload 阻断文件命令。原有业务错误、限额字段与来源拒绝保持原样。没有记录非法原值，也没有新增日志事件或计数协议；现有校验器对空关联给出未关联诊断。日志入口对非法载荷的拒收逻辑不变。

为测试真实入口执行路径，提取同文件内的私有 with_command_identity，由生产入口供应原生身份；未开放前端自报身份入口，未更改 IPC 参数或注册面。此小范围测试接缝不构成模块整理。

新增回归覆盖有效/缺失/空/含非法字符/超长 ID 下的文件写入及业务限额失败；不同未授权身份不执行命令体；tracing JSON 夹具证明合法 ID 保留、缺失/非法 ID 为空且非法原值不进入捕获输出。该夹具不等于真实 IPC 或文件 sink 的系统验收。
