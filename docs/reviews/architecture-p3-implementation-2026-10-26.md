# P3 Markdown/资源包/HTML实施审查

范围为草案6 P3。纯Markdown继续直接下载源字符串，保留CRLF且不调用渲染器；资源包通过同一ExportService接收冻结源文、联网许可和配置，再复用P2准备函数收集已校验资产。已有阅读HTML及可编辑HTML继续通过相同下载函数，CSP、文档HEX/RGB、源载荷往返和离线边界不变。

新增Markdown ZIP资源包：document.md、assets/SHA-256.扩展名及manifest.json；图片字节直接来自冻结data URL，不重新读取原URL。同哈希/类型图片只保存一份，清单保留来源、字节数、SHA-256及许可。Markdown AST定位图片/引用定义/原始HTML图片节点，按源码偏移倒序改写；不全局替换相同文本，不改代码块或无关源文，支持BOM、CRLF和转义引用标签。资源包不等于EPUB，也不增加ZIP导入；该清单是资源包说明，不冒充现有DocumentRecord载荷。

使用原已锁定JSZip 3.10.2，从devDependencies调整至dependencies；锁文件只改变根依赖分类，没有升级任何库。包内路径由固定名和受校验SHA-256构成，不采用用户路径；压缩产物超过50MiB拒收。单文件HTML保持原50MiB上限，资源读取仍受既有权限、数量和25MiB总量限制。

新增资源包单元检查源码引用、转义标签、无关源文不变、ZIP字节和清单；新增真实生产ZIP下载检查文件内容及哈希。已有普通MD下载失败清理/手动重试、HTML离线和编辑源往返、导出后继续编辑等回归继续执行。UI在统一导出窗口选择资源包并使用相同导出按钮，不增加交付状态机。PDF交互调整留给P5。
