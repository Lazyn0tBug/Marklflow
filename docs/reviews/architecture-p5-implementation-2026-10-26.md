# P5 A4 PDF导出实施审查

范围为草案6 P5。统一导出服务使用冻结源文、配置和已验证资源，先prepareExportContent，再paginatePreparedContent，以export优先级进入既有共享DOM分页步骤；不读取工作台预览DOM或要求预览完成。不更换Paged.js 0.4.3或MathJax 3.2.2。

PDF与其他格式沿用选择格式、配置、导出及反馈。流式、A4、隐藏和未完成预览均可直接导出；没有增加应用打印预览页。分页生成器保留完整页面、源映射和局部清理，导出路径跳过重复渲染/资源收集。临时交付框架在失败、afterprint或页面退出时清理。浏览器系统对话框仍属于当前Web交付方式，反馈仅“PDF导出已交由浏览器处理”，不确认文件已保存。

新增生成失败/busy释放单元及四种预览状态的真实浏览器用例，保留图片/字体/布局就绪与afterprint清理回归。首次新增用例因模拟print回调读取失效的event.target而超时，改为捕获iframe引用后复测，未放宽期限。

[PDF检查](../acceptance/architecture-p5-pdf-check.json)：从冻结分页交付文档生成受控Chromium PDF，实际5页与内部5页一致，A4尺寸正确，中英文正文与末尾标记可提取；首尾页已渲染目视检查，正文、图表、页码未见截断或覆盖。统一导出弹窗桌面截图已检查，Impeccable检测无命中。此检查不代表用户实际磁盘保存、系统对话框或实体打印验收。

验证：bun run check通过，四份严格配置覆盖166个受管源/配置，309项单元通过，lint/模块边界及生产构建通过；完整Chromium 73项通过（2.9m）。仅记录本机实际结果；其他浏览器、Tauri和Word/WPS视觉未验收。保留既有构建提示。未推送、未合并、未移动标签。
