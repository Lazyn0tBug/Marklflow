# EX-W2 手动保存补充验收（2026-10-29）

本清单补充选择器真实系统行为；不替代[EX-W0原生PDF清单](ex-w0-native-manual-checklist-2026-10-27.md)，不将受控浏览器API替身视为系统保存证明。

1. 使用已有开发/生产服务打开工作台；HTTPS或localhost且浏览器支持保存选择器时，点击统一导出按钮，确认首先出现保存位置选择。普通局域网HTTP或不支持API的浏览器应直接走下载。
2. 分别选择可编辑HTML、阅读HTML、DOCX、MD和ZIP；输入中文、长中文/emoji、空名、已有扩展名与重复扩展名，记录界面建议名、选择框实际默认名、手动修改后的名称、绝对路径和内容是否可读。保存选择器允许修改名称，因此应用建议名不等于用户最终路径。
3. 取消选择：应显示取消，无错误弹窗、无自动下载；再次点击可重新导出。选中位置后拒绝DOCX降级确认：不写正文，不打开写流，不自动删除用户选中的路径。浏览器选择器可能在返回句柄时创建新文件目录项，不能保证没有空文件；这是需记录的系统行为，不通过删除用户文件来补救。
4. 使用已有文件验证成功保存的替换行为；模拟权限/不可写位置时只报告失败，不自动下载、不宣称成功。写入阶段失败会尝试abort；实际原件保留/原子替换由浏览器文件系统实现决定，需真实文件检查，不能以替身方法调用冒充。
5. 生成失败或DOCX不支持/拒绝：不打开写流；如选择框创建了空文件，记录，不宣称应用已保存正文。后台生成期间关闭应用导出弹窗不取消已接受操作，沿用现有语义。
6. PDF仍交给浏览器原生输出，不出现本步骤的字节保存选择器；中文建议标题和系统实际默认名分别记录。保存与取消无法由应用确认，反馈只能是已交由浏览器处理。实际PDF仍按EX-W0检查。

记录模板：日期、代码提交、OS/浏览器版本、URL/是否安全环境、格式、输入名、建议名、选择框默认名、实际保存路径、取消/错误提示、原件前后状态、实际内容检查、异常说明。

当前自动化覆盖能力判断、真实点击时机、字节内容/协议和普通HTTP下载；原生选择框、覆盖/权限及真实磁盘证据尚未人工验收。EX-W3发布前按宣称支持范围补齐；未验证的浏览器/OS不宣称通过。无新增依赖或重型后备路径。
