静默 PDF 探针受控样本

本样本用于 Windows 静默 PDF 探针的固定输入，覆盖中文正文、行内公式、块级公式、表格与图片五类内容，作为 D0 交接物固化后由 D1 直接加载。样本刻意跨多页，使首尾标记落在不同页，页级断言不退化。

三、图片

图片用于确认 data URI 形式的资源在固化分页 HTML 中被内联，且在目标宿主内不依赖网络。

四、中文长段落

排版引擎在固化时会先完成一次完整的分页计算，再把结果固化为静态页面盒。因此正文的中文断行、标点避头尾、拉丁词与数字的混排宽度，都在这一步确定。本段用于提供足够的中文文本量，使样本跨越多个页面，并让首尾标记落在可区分的页上，从而让"首尾标记归预期页"成为有效断言而不是恒真断言。

这一段还用于确认段落间距、行高与段首缩进在固化后与可见工作台一致，以及长中文串在没有空格的情况下不会溢出页面盒。若某一页的中文被截断，说明该页的行盒高度不足；若出现异常空白页，说明页面盒的断页规则与预期不符。

六、代码块

const pages: number = 4;
export const frozen = true;

代码块用于确认等宽字体与中英文混排的基线表现，以及固化后不丢失换行。

七、补充中文长段落

排版的最后一类风险是分页点的位置恰好落在公式、表格或列表项中间，导致内容被割裂。本段继续提供中文文本量，使样本的分页点落在普通段落上，从而把公式与表格的完整性交给第五节的独立验证，而不是依赖分页点的运气。

当固化的页面盒数量与预期页数不一致时，优先怀疑分页计算而非宿主加载；两者由 D1c 的就绪判据分别观察，不混为一谈。
