# M3 原生 I/O 真机与跨 OS 手动验收

日期：2026-11-01。适用：`0.9.8-pre3` 之后的桌面构建与本地 `tauri dev`。对应计划阶段 **M3 原生 I/O 薄适配**（实现见 `src-tauri/src/files.rs`、`src/core/platform/tauri/files.ts`）。

## 0. 本轮要证明什么

M3 的**本机自动验证已过**（443 单元/check + 7 项 Rust 真实临时文件夹具），但计划里明确留了两条待补：**真实系统弹窗**与**跨 OS 差异**。本轮只补这两条。

**不涉及**：生产接线（M4 打开、M5 原文件保存、M9 统一导出）、发布与安装包（M10）、最终收口（M11）。

### 已实现的行为（核对时的参照，不得改写口径）

| 事实                                                                                              | 出处                                           |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 选择器**只返回 Option**：没有底层错误通道 ⇒ "未选择"与"系统弹窗故障"在应用侧**无法区分**          | `src-tauri/src/files.rs`（官方 dialog 插件）   |
| 选择结果只回传**随机文件键、显示名、大小**；路径留在 Rust 会话里，**前端拿不到路径**              | 同上                                           |
| 读键与写键**互斥**：打开键不能写、保存键不能读；`release` 撤销键，进程退出自动失效                | 同上                                           |
| 读上限 **50 MiB**（超限拒绝、不交付部分文本）、严格 UTF-8、去 BOM                                 | 同上                                           |
| 写上限 **100 MiB**（前端也拦一道）；先写同目录临时文件再 `persist` 替换；拒绝非普通目标与符号链接 | `src/core/platform/tauri/files.ts`、`files.rs` |
| **不承诺**断电持久性，也不承诺未经验证 OS 的原子替换与权限/ACL 继承行为                           | M3 评审记录                                    |

## 1. 在真机上跑夹具

夹具：`tests/fixtures/architecture/tauri-native-io-probe.html`（驱动 5 个原生命令，逐步输出 JSON；不改生产行为、不绑定文档）。

生产桌面包的 `frontendDist` 是 `dist/`，夹具不在包里 ⇒ 用 **开发模式**：

```sh
bun run tauri dev        # 需要本地 Rust 工具链；编译几分钟
```

桌面窗口打开后，在**同一个 webview** 里进入夹具页（二选一）：

- **开发工具导航**：开发模式下打开 webview 的开发者工具，在控制台执行
  `location.href='/tests/fixtures/architecture/tauri-native-io-probe.html'`；
- **临时改 devUrl**：把 `src-tauri/tauri.conf.json` 的 `devUrl` 临时指向夹具路径（**不要提交**）。

在普通浏览器里打开该页会得到 `unavailable`（原生能力只在桌面外壳可用）——这是预期，不是缺陷。

## 2. 逐步操作与记录

夹具按钮与要记的内容：

| 步骤          | 操作                                               | 记录                                                                              |
| ------------- | -------------------------------------------------- | --------------------------------------------------------------------------------- |
| 环境          | 点「环境」                                         | os / arch / 版本；是否显示"桌面外壳可用"                                          |
| 选择打开      | 点「选择打开」，在**真实系统选择器**里多选两个文件 | 显示名与大小；默认目录是什么；能否多选；取消一次（见 §3）                         |
| 读取          | 点「读取」，选一个**文本文件**（含中文）           | 长度与前 120 字符；中文是否正常                                                   |
| 读上限        | 用「读取」选一个 > 50 MiB 的文件                   | 是否被拒绝、错误文案                                                              |
| 选择保存      | 点「选择保存」，在系统保存框里**不改名字**就取消   | 见 §3                                                                             |
| 写入          | 点「写入」，选一个目标并保存                       | 回执（`saved`）；目标文件内容；**覆盖已有文件**是否正确替换；同名文件的确认框行为 |
| 释放          | 点「释放」                                         | 释放后再读是否被拒绝                                                              |
| 中文/空格路径 | 用「写入」保存到含中文与空格的目录                 | 是否成功；路径在系统框里是否正常显示                                              |

## 3. 取消

每个对话框各取消一次，记录：

| 项                                  | 记录                                             |
| ----------------------------------- | ------------------------------------------------ |
| 取消位置（系统选择器 / 系统保存框） | 待填                                             |
| 夹具输出                            | 应为"未选择目标……无法区分主动取消与系统弹窗故障" |
| 应用侧是否有别的提示                | 待填                                             |

**不要**把"未选择"写成"用户取消"——按实现的真实能力记。

## 4. 跨 OS

Windows 与 macOS **各跑一遍 §2–§3**，各写一份记录，**不互推**。重点差异项：

| 差异项                                 | Windows | macOS |
| -------------------------------------- | ------- | ----- |
| 选择器外观与默认目录                   | 待填    | 待填  |
| 保存框的默认名与扩展名                 | 待填    | 待填  |
| 覆盖已有文件是否询问                   | 待填    | 待填  |
| 目标被占用/只读时的行为                | 待填    | 待填  |
| 新建目录权限与 ACL 继承                | 待填    | 待填  |
| 中文与空格路径                         | 待填    | 待填  |
| 写入后文件是否真的替换成功（磁盘核对） | 待填    | 待填  |

## 6. 边界

- 本轮**不**修改应用行为、不接线生产路径；夹具是独立夹具。
- 只如实记录观察到的行为；没做的项写"未验证"，不写成通过。
- 若某一步失败，保留原始错误文案与截图，不做解释性转述。
