# M5-b4 原文件保存：桌面端手动验收说明

日期：2026-11-10。适用：`local-document` 分支当前的桌面构建与本地 `tauri dev`。
对应计划阶段 **M5-b4 真机证据**（六条，见《本地文档支持设计》§17.3 与 §17.2）。

## 0. 本轮要证明什么

六件事，一件一条：

1. **写回落到磁盘**：从界面上按保存，磁盘上那个文件就是那一份。
2. **门那两条分支**：目标没了与写不进去，各问一句，各走各的。
3. **状态区那句话**：目标不在了，状态区说清为什么，保存灰着而另存为可用。
4. **关闭只问写回那件**：关闭标签页只问写，放弃就关，写不回去也关得掉。
5. **冲突三选一**：覆盖、重载、取消，各有一个确定的结果。
6. **另存为与归属**：另存为写出新文件并绑定新文档，切换等在飞的那次写回完。

**本轮不证明**：跨平台差异（按 §12.5，macOS / Linux 的对话框语义归 M10）；发布与安装包；最终收口。

**自动化的部分不算这一轮。** 每一条的自动证据都在下表里，桌面上**不要重复验**；真机那一次只补"从界面点到磁盘"这一段。

## 2. 夹具与启动

桌面构建：

```sh
bun run tauri dev        # 需要本地 Rust 工具链；编译几分钟
```

**原生探针页**（可选，只覆盖原生那半）：开发模式下打开 webview 的开发者工具，在控制台执行

```
location.href='/tests/fixtures/architecture/tauri-native-io-probe.html'
```

这个页面比原来多了两步：

- **「写回落到磁盘」**：打开一个文件 ⇒ 读一次（原生侧于是有了基线）⇒ 写回 ⇒ 再读一次 ⇒ 报告里给出 `target`、`identical`，以及写下去的那一份（`written`）。`identical` 为 true 即为原生那半的证据。
- **「再问一句」**：现在答的是**状态**。把那个文件在文件管理器里删掉，再点这一步 ⇒ 报告应当说**不在了**，而不是"被改过"，也不是报错。

在普通浏览器里打开该页会得到 `unavailable`（原生能力只在桌面外壳可用）——这是预期，不是缺陷。

**准备**：

- 一个可写的本地 `.md` 文件（例如 `~/Desktop/验证.md`）；
- 知道它在文件管理器里的位置（要能删它、改它的只读属性）；
- 一个可写的目录（另存为那一步要用）。

## 3. 六条逐步操作

每一条：**先摆出那个场面** ⇒ **做那个动作** ⇒ **看该看的** ⇒ **记该记的**。

### b4-1 写回落到磁盘

1. 桌面端**打开**那个 `.md` 文件（走"打开"，不是导入）。
2. 在编辑器里改一处能认出来的地方（例如在首行加 `验证` 三个字）。
3. 按 `Ctrl/Cmd+S`。
4. **用别的应用打开同一个文件**（编辑器、文本编辑器都行）。

**该看到的**：磁盘上就是**那一份**（有那三个字）；文件开头没有 BOM；状态区那一行说**已同步**；再切回标签页，**不提示"已变化"**。

**该记的**：平台、文件路径、写前后的内容、状态区那一行。

### b4-2 门那两条分支

**其一，目标没了**：

1. 在**文件管理器里把那个文件删掉**（或者移走）。
2. 回到标签页，改一处。
3. 按 `Ctrl/Cmd+S`。
4. **该看到的**：问的是**"那个本地文件已经不在了。要继续写过去吗？继续会重新创建它。"** ⇒ 答**继续** ⇒ **那个位置被重新创建出来**，内容就是那一份 ⇒ 状态区说**已同步**。
5. 再答**否**试一次 ⇒ 问句一样 ⇒ **不写** ⇒ 状态区说**未同步**（不是失败）。

**其二，写不进去**：

1. 把那个文件设成**只读**（或用别的程序占着它）。
2. 改一处，按 `Ctrl/Cmd+S`。
3. **该看到的**：问的是**"那个本地文件写不进去了。要另存到一个新文件吗？"** ⇒ 答**另存** ⇒ **原生保存对话框** ⇒ 选一个新位置 ⇒ 写过去 ⇒ **这一份关联到新文件** ⇒ **旧文件一个字没动**。

**该记的**：两条分支各一次的提示原文、答下去之后的现象、新建出来的那个文件的内容、旧文件的字节摘要。

### b4-3 状态区那句话

1. 让那个文件在应用外消失（删掉或移走）。
2. 切回这个标签页（**不按保存**）。
3. **该看到的**：状态区那一行说**"那个本地文件已经不在了，请另存为"** ⇒ **不与"已同步"混着说** ⇒ 顶栏的**保存**灰着 ⇒ 菜单里的**另存为…**可用 ⇒ 换一个**有绑定**的标签页 ⇒ 那一行不受影响。

**该记的**：平台、消失前后的那一行、顶栏两个入口的可用状态。

### b4-4 关闭只问写回那件

1. 打开那个文件 ⇒ 改一处 ⇒ **不要保存** ⇒ 关闭那个标签页。
2. **该看到的**：只问**一句** —— **"这份文档还有没写回文件的改动。要写回文件后关闭标签页吗？"** ⇒ 答**不** ⇒ **不写回直接关** ⇒ 标签页没了 ⇒ **草稿还在工作区**（在侧栏里还能打开它，内容还在）。
3. 再改一处 ⇒ 关闭 ⇒ 答**是** ⇒ 写回然后关。
4. 再把那个文件设成只读 ⇒ 改一处 ⇒ 关闭 ⇒ 答**是** ⇒ 写不进去 ⇒ **标签页照样关掉**（**不被困住**）。

**该记的**：三种情形的现象、关掉之后工作区里那份还在。

### b4-5 冲突三选一

1. 用别的应用改那个文件的内容（改得认得出来）。
2. 回到标签页再改一处，按 `Ctrl/Cmd+S`。
3. **该看到的**：弹出的是**对话框**（不是通知）⇒ 三个选择各说清它做什么。

三种各做一次：

- **覆盖** ⇒ 文件内容**逐字节等于冻结的那份草稿** ⇒ 状态区说**已同步**。
- **重载** ⇒ 草稿**被文件那份替换**（本地改动没了）⇒ 反馈里**明说本地改动不保留**。
- **取消** ⇒ **两边都没动** ⇒ 状态区说**未同步**（不是失败）⇒ **下次保存还会再问**。

**该记的**：平台、三次各的现象、覆盖后文件的字节摘要、重载后编辑器里的内容。

### b4-6 另存为与归属

1. 打开那个文件 ⇒ 改一处 ⇒ 按 `Ctrl/Cmd+S`，**别等它写完** ⇒ 立刻点**另存为…** ⇒ 选一个新位置。
2. **该看到的**：**原生保存对话框** ⇒ 写过去 ⇒ **新文档打开** ⇒ **新文档初始即已同步** ⇒ **旧文档一个字没动**、**还是它自己的那个文件** ⇒ 切换**等已发出的那次写回完**（旧文档的"已写回"出现在**新文档打开之前**）。

**该记的**：平台、两个标签页各自的状态、新文件的内容、旧文件的字节摘要。

## 5. 结论怎么写

- **失败就记未验** ⇒ 不按已验计入 ⇒ 不拿一次通过抵六条。
- **单平台通过只计入该平台证据** ⇒ 换一台机器要重跑。
- **不宣称未实测的平台可用** ⇒ 没跑过的平台写"未验证"。
- 记完**写进《本地文档支持设计》§17.2**（实施状态）⇒ 那一轮才收口。
